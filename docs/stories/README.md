# Call stories

Real calls, with transcripts trimmed and personal details taken out. Each one taught me something about how phone conversations actually go.

[Paddle steamers in December](paddle-steamers.md) is one of the first real calls where I needed the answer. Ninety seconds, and it came back with something no website said.

[Purgatory and the security salesman](purgatory-salesman.md) is me playing a salesman against the call screener, and what it does with a pitch that makes no sense.

[The pink wallet](lost-wallet.md) goes through a supermarket voice robot and a hold queue to reach a person, and shows what the agent used to say while it waited.

[Chasing a refund](refund-call.md) is a call that read fine on paper and sounded bad on the recording. Most of the turn-taking fixes came from it.

The organic honey call is in the main [README](../../README.md).
